🐍 Python / Music Bot Example

import aiohttp

BASE = "https://your-app.herokuapp.com"
VIDEO_ID = "Zi_XLOBDo_Y"

async def get_stream_url():
    url = f"{BASE}/stream/{VIDEO_ID}?type=audio"
    async with aiohttp.ClientSession() as session:
        async with session.get(url, allow_redirects=False) as resp:
            if resp.status in (301, 302, 307, 308):
                return resp.headers["Location"]   # Direct CDN URL for PyTgCalls

# Use the returned URL directly in your music bot player

💡 Notes

redirect=true (default) → 302 to YouTube CDN → highest possible speed (often 200–1000+ MB/s).

cookies.txt is already included in this build for better success rate on age-restricted content.
